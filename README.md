# Sheffield Cross UAV Dataset

Drone imagery and ground-control data for photogrammetry experiments.

The repository contains 172 JPG images at its root, `gcp_file.txt`, and an existing `LICENSE` file. Confirm image geotags, coordinate reference systems, and the GCP format before processing.

This is a dataset resource. For mapping software, mission planning, and terrain analysis, see [AeroMap](https://github.com/Mgzz03/AeroMap).
